# NHL sources for the private statistics dashboard

Reviewed October 13, 2026. Active project: XUOIR/Sports-Intelligence-V.01. The owner clarified that the current product is a statistics tool for making their own decisions. This review prioritizes that private research use; an enterprise betting feed is not a prerequisite for a useful statistics release. Data-use permissions depend on the source and actual use, rather than the name given to the dashboard.

## Recommended order

The [complete NHL provider preflight](NHL_PROVIDER_PREFLIGHT.md) consolidates billing units, quotas/resets, freshness, rights, required fields and trial eligibility for the full shortlist. Its current decision is MoneyPuck plus the existing NHL feed and manual starter confirmation, with no additional data subscription. The owner excluded Sportlogiq from the active shortlist because its unpriced enterprise offering is not a realistic release option. Other quote-only enterprise products remain background research.

Start with the existing NHL feed, permitted MoneyPuck downloads, and a bounded offline evaluation of SportsDataverse game data. Keep source-backed starter confirmation manual initially. Use PuckIQ only if its extra context improves the tool. Spend on a small subscription only for a demonstrated gap.

## What was actually checked

Small unauthenticated checks used one transport attempt each, timeouts and bounded responses. No integration secrets, paid odds calls, OpenRouter requests, purchases or account creation were used. Findings are recorded in ignored `artifacts/nhl-low-cost-provider-research/` with actual observation times.

1. **SportsDataverse current data:** the [published NHL play-by-play release](https://github.com/sportsdataverse/sportsdataverse-data/releases/tag/nhl_pbp_lite) listed `play_by_play_lite_2027.csv`, updated October 13 at 08:03:43 UTC. A 32 KB prefix exposed shot `xg`, goalie IDs and exact 5v5 fields. A subsequent complete download, capped at 20 MB/100,000 rows, contained 28,935 rows from 89 games through October 12, season 20262027, without duplicate game/event indices. Of 5,625 exact-5v5 unblocked shot rows, 77 had missing/invalid xG, affecting **55 of the 89 games**. Do not silently drop them: incomplete games need exclusion or an explicit unavailable metric until resolved. The current Parquet asset was approximately 1.4 MB; the CSV approximately 15.9 MB. This is an evaluated candidate, not approved model evidence.
2. **PuckIQ:** one documented read-query POST to `/woodmoney` for one Edmonton 20252026 row returned HTTP 200 and approximately 1.2 KB. Actual fields included Corsi/Fenwick, Dangerous Fenwick, time on ice and a competition tier. It did not supply goalie GSAx in that sample.
3. **Project 94 discovery:** public `/v1/fields` and `/v1/seasons` returned HTTP 200; seasons included 20262027 and 20252026. The catalog exposed `xGAgainst`, `savesAboveExpected`, on-ice xG and strength fields. Catalog names do not prove GSAx equivalence or strict 5v5 definitions. No paid dataset tested. [Public field catalog](https://project94hockey.com/v1/fields).
4. **Official NHL advanced-goalie report:** one row from `api.nhle.com/stats/rest/en/goalie/advanced` returned quality-start, save-percentage and goals-against fields, with no xG/GSAx field in that response. The word "advanced" in an endpoint is not evidence that it replaces the missing model inputs.
5. **MoneyPuck:** followed published links to the current [goalie game-data ZIP](https://peter-tanner.com/moneypuck/downloads/seasonPlayersSummary/goalies/2026.zip) (41 KB, 945 rows) and [team-season CSV](https://moneypuck.com/moneypuck/playerData/seasonSummary/2026/regular/teams.csv) (86 KB, 160 rows). Actual fields include goalie `gameId`, `gameDate`, `situation`, `xGoals` and `goals`, and team `situation=5on5`, `xGoalsFor`, `xGoalsAgainst` and `xGoalsPercentage`. Basic checks found no invalid xG/goals in the goalie rows and no invalid xGF/xGA in the 32 team-5v5 rows. The team sample is a current aggregate, not rolling history; use the separately published team game-level download for prior-10-game calculations. Downloads were capped at 2 MB each; ZIP sizes/member counts were bounded without extracting paths. This verifies samples, not a deployed adapter or approved model.

## A release that does not require expensive subscriptions

**Proposed extra data-provider subscription budget: $0 initially.** This is a feasibility recommendation, not a promise that every optional feature is already complete.

- Keep existing free NHL schedules, scores and basic statistics.
- Evaluate a single advanced-data family first: MoneyPuck published files or SportsDataverse xG. Use the same definition consistently for training and live values. Show source, observation age, sample size and model name.
- Calculate rolling team 5v5 xGF/xGA and goalie GSAx from eligible completed games, excluding the target date and empty-net/shootout artifacts according to the chosen definition. These are our calculations, not claims to reproduce another provider's proprietary model.
- Record confirmed starters from an original report through a separate manual confirmation step. Missing confirmation can coexist with useful statistics; it must continue to prevent an approved recommendation.
- Keep current free/manual odds and the five-attempt rolling limit. A statistics-only detail view can work when execution prices are unavailable. Do not fabricate market edge or confidence to fill an empty module.
- Preserve the existing US$3 monthly AI ceiling, with no automatic paid reviews on data import. Hosting costs remain separate from data-provider fees.

The near-term milestone is a useful NHL matchup page with real advanced metrics and evidence provenance. Source availability and model validation are separate: current nightly data can help the former without proving the latter. A statistics release need not wait for commercial subscriptions, while approved model probabilities still require genuine validation.

## Boundaries for the import evaluation

1. Research/download code stays offline from production recommendation state initially. No data importer can create an approved model or backdate a snapshot.
2. Fetch at most one selected current-season asset per daily evaluation, with metadata checks to skip unchanged files. Import older seasons once to a local research cache; do not repeatedly download them or put millions of shot rows into the free Supabase database.
3. Cap bytes, rows, pages and requests before network admission. Pin the selected asset and hash it; retain the actual observation time and the provider's update time separately. Reject invalid IDs, ambiguous strength states, missing goalie IDs, malformed/non-finite xG and xG outside 0–1.
4. Derive aggregates from prior completed games only. Never combine cumulative season totals with duplicated game rows. Postgame goalie participation is not proof of a pregame confirmation.
5. An xG model trained using later seasons cannot be silently treated as an ex-ante historical feature. For validation, use a model trained before the evaluation period or a chronological retraining design. Preserve original source versions/corrections where available, and label reconstructed research accurately.
6. Failures retain the last valid data and its original age, enter a cooldown and cannot trigger a paid fallback. Switching the xG family changes the model's identity and requires fresh validation; it is not a transparent provider swap.

The next implementation decision is the advanced-data sample audit and aggregation contract. Paid APIs remain optional until the free route demonstrates a specific unsolved problem. No subscriptions or production spending controls were changed by this research.
