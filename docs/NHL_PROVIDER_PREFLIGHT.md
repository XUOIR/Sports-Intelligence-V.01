# NHL provider preflight and source decision

Reviewed October 13, 2026 for the active XUOIR/Sports-Intelligence-V.01 project. Scope: the NHL candidates and odds alternatives already shortlisted. Reviewed public documentation and existing local observations; no new paid data trial, account creation, subscription, vendor contact or production activation. Two MoneyPuck metadata requests and a one-byte size probe were used for download planning, not another dataset test.

## Decision

**October 14 test update:** the bounded MoneyPuck game-history audit, compressed transport, refreshed goalie pairing, isolated import and matchup UI checks passed. See [results and release safeguards](NHL_MONEYPUCK_TEST_RESULTS.md). This supersedes the earlier unknown archive-size finding; historical model approval and starter confirmation remain unresolved.

**Owner's budget correction:** Sportlogiq is excluded from the active NHL shortlist. Its actual price remains unverified; the suggested $5,000+/month is not a provider quote. Keep quote-only enterprise products as curiosity/background research, without vendor outreach, trials or additional integration work. The practical release proceeds with no additional data subscription. Published low-cost subscriptions remain optional and unpurchased.

**Best practical setup now:** existing NHL API for scores/basic data + MoneyPuck's permitted noncommercial published downloads for advanced statistics + manual confirmation from an original starter report. Keep the current free/manual odds integration. Additional data subscriptions: **$0**. This selects the next source to integrate; it does not declare the model ready or an adapter deployed.

The subsequent [BALLDONTLIE assessment](BALLDONTLIE_ASSESSMENT.md) verifies current NHL/CS2/MLB tiers and user reports. NHL ALL-STAR largely overlaps existing basic coverage; the reviewed NHL schema does not establish GSAx, ready-made 5v5 xG share or a pregame confirmed-starter feed. Keep it outside the current NHL dependency list. CS2 and MLB remain later candidates with different endpoint entitlements, not an automatic three-sport subscription.

**Budget-unrestricted curiosity only, excluded from the active plan:** Sportlogiq's hockey analytics/data API. Its documented feature fit led to the earlier premium comparison, not measured superiority or proven affordability. It offers expected-goal analysis, manpower/date filters, 300+ advanced metrics and raw API delivery. NHL Remarkable also lists goaltending, chance-quality and special-team metrics. Exact required fields, latency, use rights, quotas and price remain unverified contractual details. [Hockey API offering](https://www.sportlogiq.com/hockey/), [NHL advanced metrics](https://www.sportlogiq.com/fr/nhlremarkable/).

SportsDataIO documents an explicit projected/confirmed goalie distinction, but its commercial price is also unknown. Keep it as a background automation lead. The current starter workflow remains manual; neither it nor Sportlogiq is a dependency of the private statistics release.

Sportradar is a strong premium general NHL feed, but its reviewed Game Analytics schema lists Corsi/Fenwick and shot statistics without establishing GSAx/xG. Paying for official live coverage alone does not prove it fills the advanced-data gap. [Actual NHL analytics schema](https://developer.sportradar.com/ice-hockey/reference/nhl-game-analytics).

## Workload and safeguard decision

Use a proposed two-file/day advanced-data batch, approximately 60 file fetches in 30 days, plus a small fixed metadata allowance. That is our design, not an offered MoneyPuck quota. Import historical research once, skip unchanged files with source metadata, stream/filter large archives and store derived aggregates. A HEAD request to the published all-team game-history file returned 200 without a content length; a byte-range size probe was ignored (200, no total). Its full transport size is therefore unknown here. A hard byte cap must stop a future admitted download; do not estimate archive size from an opaque ETag or treat the previously checked 86 KB season summary as the game-history file.

Suggested first offline admission: two required files maximum, one transport attempt each, a defined total wall-clock/byte/decompressed-row budget, and no repeated request on failure. Source/schema failures retain the last valid cache and its original age, trigger a cooldown and never call another paid provider. Limits must persist in production across restarts and multiple tabs. The existing manual-odds and US$3 monthly AI rules stay unchanged.

For future goalie automation, one shared date endpoint every three minutes during eight hours is 160 calls/day, about 4,800 in 30 days. This is an estimated workload to include in a quote, not entitlement. A fixed-subscription quota does not automatically authorize infinite retries or larger polling windows.

## What remains before an integration or purchase

MoneyPuck still needs a bounded full team-game schema/completeness check, validated rolling windows, source-version handling and freshness admission. Its fee/access check does not approve our prediction model. A useful statistics view may display reliable available metrics while model predictions/verified plays remain unavailable.

Every paid quote must explicitly name GSAx or its exact derivation, strict 5v5 xGF/xGA, goalie-confirmation status/times, original publication/correction history, usable historical depth, refresh/SLA, allowed retained training data, billing currency, commitment, request/burst caps, failed-call accounting and overage behavior. Unknown terms prevent a paid trial/purchase; they are not filled with guessed figures. Budget-unrestricted curiosity is not purchase authorization.

Operating providers such as OpenRouter, Supabase, Render and the paused PandaScore integration retain their existing documented account allowances and safeguards in [API_BUDGETS.md](API_BUDGETS.md); no new account entitlement is claimed by this source review. It does not activate another sport.
